# Technical Reports

This directory contains detailed technical analysis and reports from experiments.

## Contents

- **Memory Usage Analysis**: Detailed breakdown of GPU memory consumption
- **Quantization Reports**: Impact of AWQ/GPTQ quantization on memory and quality
- **Performance Analysis**: Throughput and latency measurements

## Reports

### Memory Optimization Report

Generated by the quantization experiment:

```bash
cd experiments/quantization_memory
python quantize.py --model facebook/opt-125m --compare
```

The report includes:
- Baseline memory usage (FP16)
- Quantized memory usage (AWQ)
- Memory savings in GB and percentage
- Inference quality comparison

### Sample Report Structure

```json
{
  "title": "Memory Optimization with AWQ Quantization",
```

## Key Findings

### Memory Optimization
- AWQ quantization typically reduces memory by 70-75%
- Minimal quality degradation (<1% on standard benchmarks)
- Enables serving larger models on consumer GPUs

### Throughput Improvements
- vLLM achieves 2-10x throughput over standard transformers
- Continuous batching maximizes GPU utilization
- PagedAttention reduces memory fragmentation
